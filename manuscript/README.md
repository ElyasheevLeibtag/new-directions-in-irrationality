# Reference manuscript

`main.tex`, `preamble.sty`, `references.bib` and the figures referenced by
the active main source are copied byte-for-byte from
`New_Directions_In_Irrationality___Focused.zip`.

Unused drafting appendices, backup preambles and older embedded certificate
sets are omitted. The original archive checksum is recorded in
`../provenance/input_archives.json`. This directory is a reference snapshot,
not a newly compiled or corrected edition. Proposed corrections are in
`../MANUSCRIPT_ALIGNMENT.md`.

Figure exports are included for reading and manuscript compilation. Their
raw plotting data and generators were not present in the received archives.
