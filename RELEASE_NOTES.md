# Release notes — 1.0.0-rc2

Prepared 19 October 2026. This combined release candidate retains the tested
Python supplement from rc1 and adds all 256 Lean source files from three
author-selected RamanujanMachine repositories. Each copied source and
configuration file is unchanged and checked against its upstream Git blob.

Added exact revision and dependency records, a theorem-to-project guide,
explicit PNT assumptions, and a build driver that checks the substantive
`zetas_irr` entry points rather than just its default stub target. No
independent Lean compilation is claimed. Historical upstream handoff notes
and unrelated experimental outputs are omitted.

The nine Python notebooks and eight additional checks passed in rc1. Their
code and saved results are unchanged. The manuscript snapshot is also
unchanged; suggested corrections remain a separate patch and alignment note.

The archive can be uploaded to a Zenodo draft. Before final publication,
choose licensing terms, confirm author metadata, and finalize the paper's
availability wording. The public paper repository is https://github.com/ElyasheevLeibtag/new-directions-in-irrationality.
